# GymAIPlanner

GymAIPlanner is a full-stack AI-powered fitness application that generates personalized workout programs based on a user's goals, experience level, training availability, equipment access, and preferences.

Users can create an account, complete a fitness questionnaire, and receive a structured training plan generated by AI. User profiles and generated plans are persisted so users can return to their plan and generate updated versions over time.

## Live Demo

**[Try GymAIPlanner](https://gym-ai-planner-seven.vercel.app)**

## Features

### Authentication

* User sign-up and sign-in
* Persistent authenticated sessions
* User-specific profile and training plan data
* Neon Auth integration

### Personalized Onboarding

Users complete a fitness questionnaire containing:

* Fitness goal
* Training experience
* Days available per week
* Preferred session length
* Available equipment
* Injuries or limitations
* Preferred workout split

The profile is stored in the database and used when generating personalized training programs.

### AI-Generated Training Plans

GymAIPlanner uses an AI model through OpenRouter to generate structured workout programs based on each user's profile.

Generated plans include:

* Weekly training schedule
* Exercises
* Sets and repetitions
* Rest periods
* Exercise notes
* Training progression guidance

### Persistent Training Plans

Generated plans are stored in PostgreSQL rather than existing only in the current browser session.

Returning users can sign back in and immediately access their latest training plan.

### Plan Regeneration

Users can generate another variation of their training program.

Each generated plan receives a version number, allowing multiple generations to be maintained in the database.

### Responsive Design

The interface is designed for both desktop and mobile use, allowing users to access their training program while at the gym.

## How It Works

1. A user creates an account or signs in.
2. New users complete the fitness onboarding questionnaire.
3. The React frontend sends the profile to the Express REST API.
4. Profile information is persisted in PostgreSQL using Prisma.
5. The backend constructs an AI prompt using the user's training preferences.
6. The request is sent to an AI model through OpenRouter.
7. The model returns a structured training program.
8. The generated plan is persisted in PostgreSQL.
9. The frontend retrieves and displays the user's latest plan.
10. Returning users can access their existing plan or generate another version.

## API

The Express backend exposes REST endpoints for profile and training plan management.

### User Profile

```text id="om9n8j"
POST /api/profile
```

Creates or updates a user's fitness profile.

### Generate Training Plan

```text id="ny4dqx"
POST /api/plan/generate
```

Generates a new AI training plan using the user's saved profile and persists the result.

### Current Training Plan

```text id="tjmjsy"
GET /api/plan/current?userId={userId}
```

Retrieves the user's most recently generated training plan.
